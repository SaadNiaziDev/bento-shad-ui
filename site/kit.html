Rules for bento layouts

What keeps a bento page calm instead of busy.

  • One idea per tile. If a tile needs a second heading, split it.
  • Size by importance. The main thing gets 2 × 2; supporting facts get 1 × 1.
  • Tint sparingly. At most one toned tile in four, and only one inverse tile per view.
  • Fill every row. Pick spans that add up to 4. Dense flow fills small gaps.
  • Same padding everywhere. Change tile size, never the inner padding.
  • Flat tiles, floating overlays. Shadows only on menus, dialogs and toasts.

04 · Usage

Install and use

Pick the layer for your stack. Full guides are in docs/, and AI agents can read llms-full.txt.

Install

Straight from GitHub. Always pin a tag.

npm install github:SaadNiaziDev/bento-shad-ui#v0.1.1
bento-shad-ui/bento.cssTokens and every component. Any website or web app.
bento-shad-uiTyped vanilla core: theme, toasts, popovers, tabs, command, calendar. SSR-safe ESM.
bento-shad-ui/autoThe core, started on import.
bento-shad-ui/reactReact components with TypeScript types, marked "use client".
shadcn-theme.cssglobals.css for shadcn/ui on Tailwind v4, plus bento utilities.
r/*.jsonshadcn registry items: bento-theme, bento-grid.
flutter/bento_theme.dartThemeData for light and dark, every token as a ThemeExtension.
llms.txtDocs index for AI agents; llms-full.txt has every guide.

Plain HTML, from the CDN

No build step. The script exposes window.BentoUI.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SaadNiaziDev/bento-shad-ui@v0.1.1/dist/bento.min.css">
<script src="https://cdn.jsdelivr.net/gh/SaadNiaziDev/bento-shad-ui@v0.1.1/dist/bento.iife.min.js" defer></script>

<body class="bk">
  <div class="bk-bento"><div class="bk-bento-grid">
    <article class="bk-tile bk-span-2">…</article>
    <article class="bk-tile" data-tone="peach">…</article>
  </div></div>
</body>

React and Next.js

Typed, controlled or uncontrolled, asChild for router links.

import 'bento-shad-ui/bento.css';
import { BentoGrid, Tile, Stat, Button, toast } from 'bento-shad-ui/react';

<BentoGrid>
  <Tile span={2} rows={2} tone="inverse">
    <Button variant="brand" onClick={() => toast('Saved')}>Save</Button>
  </Tile>
  <Tile tone="peach"><Stat label="Bookings" value="1,284" /></Tile>
</BentoGrid>

shadcn/ui + Tailwind v4

Keep shadcn's components. Add the theme and the grid from the registry.

npx shadcn@latest add https://raw.githubusercontent.com/SaadNiaziDev/bento-shad-ui/v0.1.1/r/bento-theme.json --overwrite
npx shadcn@latest add https://raw.githubusercontent.com/SaadNiaziDev/bento-shad-ui/v0.1.1/r/bento-grid.json

<BentoGrid>
  <BentoTile span={2} rows={2}><Card>…</Card></BentoTile>
  <BentoTile tone="peach">…</BentoTile>
</BentoGrid>

Flutter

Copy one file into lib/. Add the two Red Hat fonts.

MaterialApp(
  theme: BentoTheme.light(),
  darkTheme: BentoTheme.dark(),
);

final c = Theme.of(context).extension<BentoColors>()!;
Container(
  padding: const EdgeInsets.all(BentoTheme.tilePadding),
  decoration: BentoTheme.tile(c, color: c.tintPeach),
);

Rebrand

Override tokens after the kit's CSS. Keep text at 4.5:1 and rings at 3:1.

:root {
  --brand: oklch(0.62 0.19 255);
  --brand-foreground: oklch(0.99 0 0);
  --ring: oklch(0.52 0.19 255);
  --tile-radius: 1.25rem;
}
